
# SensorGrid

A simple responsive sensor monitoring interface with ESP32 LED blinking.

## Features

- Responsive web interface
- Dashboard
- Sensor status
- Alert section
- ESP32 LED blinking

## Hardware

- ESP32 development board
- Built-in LED

## Software

- HTML
- CSS
- Arduino IDE

## ESP32

The ESP32 built-in LED turns ON for 1 second and OFF for 1 second.
